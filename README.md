# RADS: Roblox Advanced Diagnostics Suite

  RADS is an advanced diagnostics toolkit built for Roblox developers. It gives you a structured way to inspect, test, and troubleshoot your experiences while you build them.

## Intended Use

  RADS is designed for **development and testing environments**. It is meant for developers who need to run diagnostics when certain settings are disabled, such as when `loadstring` is unavailable or has been switched off in an experience.

It is provided for legitimate development, debugging, and analysis purposes only.

## Not an Exploit

  RADS is **not** an exploit and was not designed or tested as one. Using it as an exploit is strongly discouraged. Outside its intended environment you should expect:

    - Unstable or inconsistent behavior
    - Errors, crashes, and glitches
    - Features that fail to work or work only partially
